# قالب سفره‌خانه دیگ‌آوا

قالب HTML فارسی (راست‌به‌چپ) برای رستوران و فروشگاه غذای سنتی. بدون فریمورک و بدون نیاز به نصب یا بیلد.

## شروع سریع
1. پوشه را روی هاست آپلود کنید (یا `index.html` را باز کنید).
2. فایل `assets/js/config.js` را ویرایش کنید: نام، شماره، آدرس، کانال‌های سفارش، رنگ و تم.
3. منو و قیمت‌ها: `assets/js/data.js`
4. عکس‌ها: طبق `assets/img/dishes/README.txt` نام‌گذاری و در همان پوشه بگذارید.
5. آدرس سایت را در `config.js` (`url`)، `robots.txt` و `sitemap.xml` بگذارید.

## ساختار
- `index.html` صفحه‌ی اصلی؛ `docs.html` راهنمای کامل؛ `404.html` صفحه‌ی خطا
- `assets/css` استایل‌ها؛ `assets/js` منطق؛ `assets/img` تصاویر

## فونت
فونت‌ها از Google Fonts بارگذاری می‌شوند. برای استفاده‌ی آفلاین یا بدون وابستگی بیرونی، فایل‌های Vazirmatn و Markazi Text را در `assets/fonts` بگذارید و با `@font-face` در `assets/css/base.css` معرفی کنید.

## نکته
ثبت سفارش و حساب کاربری سمت مرورگر ذخیره می‌شوند و برای پشتیبان‌گیری سرور نیاز ندارند؛ سفارش‌ها به کانال‌هایی که در `config.js` پر کنید ارسال می‌شوند.
